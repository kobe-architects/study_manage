# Focus Gold 数学Ⅰ+A 例題 → 4 択データの文字起こし

あなたの仕事: 指定されたページ画像（PNG。教科書のスキャン）を 1 枚ずつ Read ツールで見て、各例題の
「答え」「誤答の選択肢 3 つ」を JSON に書き出す。画像以外の情報源はない。

## 画像
- `p001.png` … `p322.png` が例題 1 … 322 のページ（ファイル番号 = 例題番号）。
  ページの構成: 上に「例 題 N タイトル」の枠（問題）→「考え方」→「解答」（右に補足の注）→「Focus」の枠（要点）→ 一番下に「練習 N」。
  **「練習」は別の問題なので無視する。** 答えは「解答」の中の結論だけ。
- `p017_2.png` `p017_3.png` のように `_2` `_3` が付くものは、その例題の解答の続きのページ（解答が長いとき）。
  ただし続きではなく別の内容（「Step Up」「まとめ」「章末問題」など）のページが混ざっていることがある。その場合は無視する。
  必ず `_2` も見てから答えを決めること（解答が次ページに続いていることがある）。

## 出力
出力先ファイル（指示されたパス）に、次の形式の JSON 配列を書く（UTF-8、ensure_ascii しない）。要素はファイル番号順。

```json
[
  {
    "no": 1,
    "title": "整式の整理",
    "subs": [
      { "label": "(1)", "answer": "x: 2 次式，係数 3x²−2y³，定数項 4y³ ／ y: 3 次式，…", "options": ["…", "…", "…"] },
      { "label": "(2)", "answer": "…", "options": ["…", "…", "…"] }
    ],
    "skipped": ["(3) グラフをかく問題のため"],
    "note": ""
  }
]
```

- `no`: ファイル名の番号（p007.png → 7）。
- `title`: 枠の見出し（「例 題 N」の右の題名。例「整式の加法・減法」）。
- `subs`: 4 択にする小問。問題の小問ごとに 1 つ（(1)(2)…。(2)(ア)(イ) のように入れ子なら "(2)(ア)" のように 1 つの label にする）。
  小問が無い問題は label を null にして 1 つだけ。
  - `answer`: その小問の**最終的な答え**を文字で。「解答」の最後の結論（太字の式、「よって」「したがって」の後、または最終行）を使う。
    途中式は書かない。複数の答えは「，」や「 ／ 」で 1 つの文字列にまとめる（例「x=1，4」「a=−1」「最大値 5 (x=2)，最小値 −3 (x=0)」）。
  - `options`: **誤答** 3 つ。正解と同じ形式・同じくらいの長さで、ありそうな間違い（符号違い、係数違い、指数違い、分母分子の入れ替え、
    場合分けの境界の取り違え、計算ミスの結果など）にする。正解と同値の式（並べ替えただけ・約分しただけ等）を誤答にしてはいけない。3 つは互いに異なること。
- `skipped`: 4 択にできない小問とその理由（「グラフをかけ」「証明せよ」「示せ」「図示せよ」など、答えが文字で表せないもの）。無ければ空配列。
  「グラフをかけ。また，最大値を求めよ」のように値も求めるなら、値の部分で 4 択にする（skipped にしない）。
  すべての小問が 4 択にできないときは subs を空配列にする。
- `note`: 読み取りに自信が無い箇所があれば短く（無ければ ""）。スキャンで字がつぶれて読めないときもここに書く。

## 数式の書き方（画面にそのまま文字で出す。Unicode を使う）
- 指数: x², x³, x⁴, x⁵, x⁻¹, a^n（上付きにできない文字は ^ を使う。例 2^n, x^(n+1)）
- 分数: 1/2, (x+1)/(x−2), 3/√2。分子・分母が 2 項以上なら括弧で囲む。帯分数は使わない。
- 根号: √2, √(x+1), ³√2
- マイナスは「−」（U+2212）、掛け算は省略するか「×」、点は「・」。≦ ≧ ≠ ± π ∞ θ Σ を使う。
- 添え字: a₁, aₙ, x₁（下付きにできない文字は _ を使う）。
- 角度: 30°、三角比: sin30°, cosθ, tan²θ
- 区間・集合: 1<x<3, x≦−1 または x≧2, {1, 2, 3}
- 日本語の答え（「3 次式」「12 通り」「平行」など）はそのまま日本語で。

## 進め方
- 画像は 1 ページずつ順に Read する（1 回の呼び出しで 2〜3 枚まとめて読んでよい）。
- 20 枚ごとを目安に、それまでの分を出力ファイルに書き足して保存する（途中で止まっても残るように）。最後に全件そろった配列を書き直す。
- 要素の数 = 担当範囲のページ数になることを最後に確認する。
- Python などで JSON の妥当性を確認してから終える（`python -I -c "import json;json.load(open(path,encoding='utf-8'))"`）。
- 完了の報告は、件数・subs の総数・skipped の件数・自信の無い箇所を簡潔に。
