# スタディサプリ ベーシックレベル数学 例題 → 4 択データの文字起こし

あなたの仕事: 指定されたディレクトリにあるページ画像（PNG）を 1 枚ずつ Read ツールで見て、各例題の
「見出し」「答え」「誤答の選択肢 3 つ」を JSON に書き出す。画像以外の情報源はない（PDF に文字データは無い）。

## 画像
- `p001.png`, `p002.png`, … が例題 1 枚目のページ（上が問題、点線の下が［解答］）。
- `p004_2.png` のように `_2` `_3` が付くものは、その例題の解答の続きのページ。必ず続きも見てから答えを決めること。
- ページ上部の灰色の帯に「第N講 講のタイトル」（講の先頭ページだけ）と「PARTn PART のタイトル」がある。
  講の番号は、帯に無いページでは右上の小さな黒いタグ「第N講 PARTn」から読む（数字が小さいので注意。直前のページと同じ講なら同じ番号）。
- 問題の左上の黒い四角の中の数字が「例題番号」（講の中での通し番号）。

## 出力
出力先ファイル（指示されたパス）に、次の形式の JSON 配列を書く（UTF-8、ensure_ascii しない）。要素はページ画像の番号順。

```json
[
  {
    "no": 1,
    "lecture": 1,
    "lectureTitle": "式の計算と展開",
    "part": 1,
    "partTitle": "単項式と多項式",
    "label": 1,
    "subs": [
      { "label": "(1)", "answer": "係数 −3x²y³，次数 1 ／ 係数 −3ay³，次数 2", "options": ["係数 −3x²y³，次数 2 ／ 係数 −3ay³，次数 1", "係数 3x²y³，次数 1 ／ 係数 3ay³，次数 2", "係数 −3ax²，次数 3 ／ 係数 −3ax y²，次数 3"] },
      { "label": "(2)", "answer": "x に着目: 2 次式，定数項 −2y³+4 ／ y に着目: 3 次式，定数項 3x²+x+4", "options": ["…", "…", "…"] }
    ],
    "skipped": ["(3) グラフをかく問題のため"],
    "note": ""
  }
]
```

- `no`: ファイル名の番号（p007.png → 7）。
- `lecture` / `lectureTitle` / `part` / `partTitle`: 帯とタグから。タイトルは帯の文字どおり（例「2次関数の最大・最小，2次関数の決定」）。
- `label`: 黒い四角の中の例題番号（整数）。
- `subs`: 4 択にする小問。問題の小問ごとに 1 つ（(1)(2)… 。(2)(i)(ii) のように入れ子なら "(2)(i)" のように 1 つの label にする）。
  小問が無い問題は label を null にして 1 つだけ。
  - `answer`: その小問の**最終的な答え**を文字で。解答欄の最後の結論（「よって」「したがって」の後、または最終行の式）を使う。
    途中式は書かない。複数の答えがある小問は「，」や「 ／ 」で 1 つの文字列にまとめる（例「x=1，4」「(1, 2)，(4, 5)」）。
  - `options`: **誤答** 3 つ。正解と同じ形式・同じくらいの長さで、ありそうな間違い（符号違い、係数違い、指数違い、分母分子の入れ替え、
    計算ミスの結果など）にする。正解と同値の式（並べ替えただけ・約分しただけ等）を誤答にしてはいけない。3 つは互いに異なること。
- `skipped`: 4 択にできない小問とその理由（「グラフをかけ」「証明せよ」「示せ」「図示せよ」「表を完成」など、答えが文字で表せないもの）。無ければ空配列。
  小問の一部が「グラフをかけ。また，漸近線を求めよ。」のように値も求めるなら、値の部分で 4 択にする（skipped にしない）。
  すべての小問が 4 択にできないときは subs を空配列にする。
- `note`: 読み取りに自信が無い箇所があれば短く（無ければ ""）。

## 数式の書き方（画面にそのまま文字で出す。Unicode を使う）
- 指数: x², x³, x⁴, x⁵, x⁻¹, a^n（上付きにできない文字は ^ を使う。例 2^n, e^x, x^(n+1)）
- 分数: 1/2, (x+1)/(x−2), 3/√2。分子・分母が 2 項以上なら括弧で囲む。帯分数は使わない。
- 根号: √2, √(x+1), ³√2
- マイナスは「−」（U+2212）、掛け算は省略するか「×」、点は「・」。≦ ≧ ≠ ± π ∞ θ Σ ∫ を使う。
- 添え字: a₁, aₙ, x₁（下付きにできない文字は _ を使う）。ベクトルは →a または AB→ のように矢印を後ろに。
- 角度: 30°、三角比: sin30°, cosθ, tan²θ
- 区間・集合: 1<x<3, x≦−1 または x≧2, {1, 2, 3}
- 対数: log₂8, log₁₀2, logₐx。極限は lim（lim[x→∞] のように）。
- 日本語の答え（「3 次式」「12 通り」「平行」など）はそのまま日本語で。

## 進め方
- 画像は 1 ページずつ順に Read する（1 回の呼び出しで 2〜3 枚まとめて読んでよい）。
- 50 枚ごとを目安に、それまでの分を出力ファイルに書き足して保存する（途中で止まっても残るように）。最後に全件そろった配列を書き直す。
- 要素の数 = ページ画像（`_2` などの続きを除く）の数になることを最後に確認する。
- Python などで JSON の妥当性を確認してから終える（`python -I -c "import json;json.load(open(path,encoding='utf-8'))"`）。
- 完了の報告は、件数・subs の総数・skipped の件数・自信の無い箇所を簡潔に。
